TokenMe v0.1.0：把本地 AI 使用记录变成可收藏、可分享的个人足迹。

- Codex / WorkBuddy 采集，ccusage JSON 桥接，可选 Codex 官方摘要。
- 持久历史、去重、月报、白名单备份恢复与离线重建。
- 累计 I 量、五档材质、竖版/方版 PNG 与可关闭的传播二维码。
- 零第三方运行依赖；需要 Python 3.10+ 和现代浏览器。

源码包运行 `python -m token_footprint scan --open`；安装 wheel 后运行 `tokenme scan --open`。

常规网页/App 全量账号、跨设备自动同步、排行榜和桌面安装器不在本版范围。请阅读 README 的数据边界；未接入不等于零用量。扫码进入项目，不公开个人数据。
